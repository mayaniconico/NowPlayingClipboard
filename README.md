# なうぷれコピー

Windowsで現在再生中の曲とサムネイルを取得し、X（Twitter）投稿用の文章をクリップボードへコピーするツールです。
APIキーやXアカウントとの連携は不要です。

## 使い方

1. Spotify、MusicBee、ブラウザなどで曲を再生します。
2. `起動（画面を隠す）.vbs` をダブルクリックします。
3. 曲名とジャケット画像を確認し、必要なら投稿文を編集します。
4. `クリップボードへコピー` または `コピーしてXの投稿画面を開く` を押します。
5. 画像も使う場合は `画像コピー` でコピーし、Xの投稿画面へ貼り付けます。

## テーマ

- 初回起動時はWindowsのライト／ダーク設定に自動追従します。
- 右上のテーマボタンを押すと、`自動 → ライト → ダーク` の順に切り替わります。
- 選択したテーマは `settings.json` に保存され、次回起動時にも引き継がれます。

取得される標準の投稿文は次の形式です。

```text
曲名 / アーティスト #NowPlaying
```

## 対応環境

- Windows 10 / 11
- Windowsの音量パネルやメディア表示に曲名が出るプレイヤー
- Spotify、MusicBee、Chrome、Edgeなど（各アプリ側の対応状況によります）

## うまく取得できない場合

- 曲を実際に再生した状態で `更新` を押してください。
- Windowsの音量・メディア表示に曲名が表示されるか確認してください。
- ブラウザ再生では、動画や音楽のタブを一度操作してから再試行してください。
- プレイヤーがサムネイルを提供していない場合、曲情報だけが表示されます。
- サムネイル取得には同梱の補助プログラムと.NETランタイムを使用します。
- エラーの詳細は `logs\now-playing.log` に記録されます。

## ファイル

- `NowPlayingClipboard.ps1`: 本体
- `ThumbnailFetcher.exe`: サムネイル取得用の補助プログラム
- `起動（画面を隠す）.vbs`: 通常はこちらから起動
- `起動.cmd`: エラー確認用。PowerShell画面を表示して起動
